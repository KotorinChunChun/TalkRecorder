## 継承した要求と設計判断

| 項目 | 決定と実装 |
| --- | --- |
| 収録と同期 | Windows 11 の WASAPI でマイク最大2台・スピーカー最大2台を別トラックに収録し、共通の時間軸に揃える。リモート機器の時計が不安定な場合は、受信時計とデバイスのフレーム位置から安定区間の時刻を推定する。補正できない区間の音は保持する。 |
| 会話判定 | スピーカーから流れる会話も対象に含める。標準判定には VAD を使い、Haas による補助認識は任意。未処理、切断、時計異常、解析失敗は非発話と区別する。 |
| 共通編集 | 既定では録音開始または前回分割から実時間600秒以降に、全機器共通の非発話が10秒続く位置で分割する。共通の非発話は3秒まで短縮し、各しきい値は変更できる。全機器で対象区間のすべてが非発話と判定された場合は公開ファイルを確定しない。 |
| 連続保存と復旧 | 内部音声とチェックポイントを定期保存し、データを解放する。累積4GBを停止条件にしない。再接続・スリープ復帰・異常終了時は、確定済み音声と回収可能なデータを保護する。 |
| 保存と圧縮 | M4A・Opus・FLAC・WAVに対応。WAV自動圧縮を有効にした場合は新規WAV指定時もM4Aへ保存し、既存WAVは変換後の形式・尺・サンプル数を検証してから切り替える。 |
| ノイズ除去 | 初期値はOFF。RNNoise、DeepFilterNet3、RE-USEを選択可能。EXE配下の定義・DLL・モデルが揃った方式だけを一覧に出し、開始前に選んだ方式の出力と応答を確認する。 |
| 画面と設定 | 録音せずに波形を確認できる。通知領域から復帰・終了でき、状態は画面非表示でも更新する。同一ログオンセッションでGUIは1つ。デバイス選択だけを部分保存し、同名別IDの機器へ自動切替しない。 |
| 空き容量 | 容量不足の事前通知案は採用しない。設定した空き容量以下で録音の取得を停止し、通常の保存手順で処理済み音声を確定する。しきい値は変更・無効化できる。 |

## 統合前の主な検証

以下は過去の検証記録であり、今回のリポジトリ整理後に再試験した結果ではない。

- リモートマイクとスピーカーを各1台、約74秒同時収録した。全機器共通の非発話5秒をカットし、両M4Aが48kHz、69.042146秒、実復号3,314,023フレームで一致した。
- 同じ発話を[独立した複製経路](../../research/native-reference/README.md)で比較した。前後の遅延中央値差は0.5ms、複製経路の遅延を差し引いた代表的な残差は約24ms。受信側の時計に基づく結果で、接続元で発声してからの絶対遅延は未測定。
- 模擬容量で取得停止、キューと遅着した末尾の保存、2トラックの同尺WAV確定を確認した。追加のM4A試験で実復号フレーム数を照合。ディスク自体を枯渇させる試験はしていない。
- 合成データによる4トラックの編集・保存、異常時の原音保持、圧縮中断からの復旧を確認した。単一GUI、通知領域と機器設定の部分保存は旧実行ファイルでも確認した。
- 3方式のノイズ除去を公開音声で確認した。試験環境のRE-USEは処理が応答期限を超えた。処理負荷や品質は機器と入力音声で変わる。
- RNNoiseでは公開音声6秒の288,000フレームを同数で返し、波形相関は約0.9949、ピーク位置差は0サンプルだった。DeepFilterNet3では公開音声3秒で、設計上の遅延30msを補償した後に相関0.911665、最良の位置差0サンプルを確認した。

## 初回版の整理後に確認したこと

- 本体の自動テストは183件成功。実機・外部ツール・モデルを要する18件は通常テストの対象外。
- プラグインの通常テストはRNNoise 5件、RE-USE 1件、DeepFilterNet3 1件に成功。DeepFilterNet3の実モデル・実DLLを使う3件は対象外。
- `TalkRecorder.exe` のCLIで、隔離した初期設定の生成と保存先の空き容量照会を確認した。実録音・既存設定・GUIは使用していない。
- Rustの整形、PowerShellの構文、資料の相対リンク、Gitの除外ルールを確認した。Clippyは1.99で既存コードに出る `chunks_exact_to_as_chunks` の7件だけを対象外にして成功した。

## 継続確認

- 4物理機器での同期と24時間以上の連続運転、実機の抜き差しとスリープ復帰、録音中の通知領域からの終了。
- 小声・同時話者・雑音を含む会話の判定品質とノイズ除去が発話に与える影響。
- 原音の恒久保存、削除保留、波形への発話表示、録音予約、録音一覧・再編集、字幕出力は未実装。

## 初回公開候補

開発時にローカルで使っていた版番号を v0.1.0 に戻し、KotorinToys 経由の常駐・自動録音と、容量照会エラーからの復帰も含めた。Windows x64 のポータブル ZIP に、EXE、利用案内、依存のライセンス、ハッシュ付き準備スクリプトを入れる。音声ランタイムと FFmpeg は初回に元の配布先から取得する。

- 本体の通常テスト183件と、FFmpegを使う合成4トラックの保存試験4件に成功した。
- 配布ZIPを展開して、環境準備、EXEの版、初回設定、標準VAD、空き容量の確認を実施した。無表示起動と録音OFF、PID照合、管理要求での表示・終了も確認した。
- 配布EXEで「デバイス」「保存・時間」「音声処理」の画面を描画し、初回設定を確認した。リモートのマウス・キーボードによる操作はアクセス拒否で確認できなかった。画面録画は対象ウィンドウを前面化できず、その代わりに3画面の実描画を確認した。
- 収録対象の個人データは含めず、ビルドしたEXEの開発PCの絶対パスと配布ZIPの内容を確認した。

GitHub で v0.1.0 をポータブルの開発版として公開した。採用コミットは `1f236be`。公開した ZIP とハッシュ台帳を匿名で取得し、ローカルで検証した ZIP と照合した。SHA-256 は `8281ed55793f9694b2989d8268517b579e2cb54e33479e1fa545903a205799ed`。KotorinToys の公開一覧と README には配布元のリンクを掲載した。 [GitHub Release](https://github.com/KotorinChunChun/TalkRecorder/releases/tag/v0.1.0)
